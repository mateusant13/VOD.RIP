# ── GPU transcription upgrade (NVIDIA, any GPU >= 6 GiB VRAM) ────────────
# Plain `pip install -r requirements.txt` keeps CPU sherpa-onnx; run THIS
# file instead on an NVIDIA host to swap in the CUDA-enabled wheel (the lane
# probes the installed wheel at runtime and stays whisper on GPU slots when
# CUDA is absent, so installing it on a CPU-only machine is harmless).
#
#   pip install -r requirements-gpu.txt
#
# The +cuda wheel bundles its own CUDA-enabled onnxruntime (no separate
# onnxruntime-gpu install). It loads cublasLt64_12/cufft64_11/curand64_10/
# cudnn64_9 from PATH (Windows) / LD_LIBRARY_PATH (POSIX) at session create
# — nvidia-cublas-cu12 + nvidia-cuda-runtime-cu12 are already pulled by
# faster-whisper/ctranslate2 in requirements.txt; the wheels below add the
# rest, and archive_transcribe._ensure_cuda_libs exposes their bin/lib dirs.
--find-links https://k2-fsa.github.io/sherpa/onnx/cuda.html
-r requirements.txt
sherpa-onnx==1.13.4+cuda12.cudnn9
nvidia-cufft-cu12
nvidia-curand-cu12
nvidia-cudnn-cu12
